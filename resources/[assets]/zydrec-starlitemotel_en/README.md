# Starlite Motel
The Starlite Motel has been fully renovated, turning the abandoned property into a fresh and functional motel in the heart of East Vinewood. The motel includes 30 empty motel rooms where players have the freedom to furnish and customize each room to suit their own style and needs.

# key features
* 30 motel rooms for players to furnish however they'd like.
* Full rework of the motel with proper LODs
* Detailed exterior

# installation
This asset delivers 1 resource which includes the exterior & interior.

* Download the repo as a ZIP by clicking the green button the top right (ignore this step if you have it through tebex)
* extract the folders `zydrec-starlitemotel` into your resources folder
* ensure the assets in your server.cfg
```
ensure zydrec-starlitemotel
```
Thats it!
I would also suggest grabbing the mapdata [here](https://github.com/Zydrec/zydrec-mapdata) in order for doors & gates to function correctly and have audio. Also ignore this if you got the package through Tebex, you'll have the mapdata in your portal already.
