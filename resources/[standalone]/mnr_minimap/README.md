## MONARCH MINIMAP
A rework of the V2 of the famous script ExtraMapTiles made only to simplify the way of installing postal maps for server owners and also automate the customization of them introducing a new and unique way to load map tiles thanks to the studies of [manups4e](https://github.com/manups4e) that created the first scaleform for minimap usage (used also in ExtraMapTiles V1) and to [AlexLicuriceanu](https://github.com/AlexLicuriceanu) that found the practical usage for it with ExtraMapTiles and continued his studies on the script creating [extra-map-tiles-v2](https://github.com/AlexLicuriceanu/extra-map-tiles-v2)

## FEATURES
- Automatic mods detection (Only Cayo for atlas map at the moment) and loading of needed textures.
- Configuration and setup of radar and pause menu zoom level values.

## WORK DONE
- Scaled the 3072x3072 textures to power-of-2 dimensions (4096x4096) for mipmap compatibility.
- Ensured DXT5 format for all textures to support transparency.
- Reworked script parts to reduce loops iterating on tiles config.
