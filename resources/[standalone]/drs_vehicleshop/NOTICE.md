# DRS Vehicle Shop Fork Notice

`drs_vehicleshop` is a DRS-maintained modified fork of QR Development's `qr-vehicleshop`:

https://github.com/QRDevelopment/qr-vehicleshop

The original source is distributed under the MIT License. The included `LICENSE` file and its RaySist copyright notice are retained unchanged.

This DRS release starts from the completed custom Qbox/DRS integration build. DRS modifications include the renamed runtime and API namespace, Qbox and QB framework support, DRS Garages integration, multi-shop vehicle sales, server-authoritative checkout and delivery, durable purchase recovery, automatic database compatibility setup, test-drive controls, and the reworked vehicle-shop interface.
